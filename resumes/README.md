# resumes/

Your source material lives here. Everything in this folder except this README is gitignored, so it stays on your machine.

Put in:

- **Your current CV** (PDF, DOCX or Markdown). Claude reads it during `/setup`.
- **`asset-brief.md`** (optional, written during `/setup`): the long version of your story. Full experience text, case studies with metrics, customer quotes, and which proof point to lead with for which kind of role. The app's profile holds the short version. This file is where the detail lives when tailoring a CV.
- Any tailored CV variants you want to keep.
